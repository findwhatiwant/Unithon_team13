Magic Note — User Flow

Unithon Team13 · v0.3 · ● = 사용자 행동 · ◆ = 판단/분기 · 시스템 응답 포함
Flow A · 앱 실행 → 첨삭 → 리포트
1
USER

앱 실행

Applications에서 Magic Note 실행

2
SYSTEM

로그인 화면 표시

중앙에 적당한 크기의 로그인 윈도우 오픈
이미 로그인 세션이 있으면 바로 문서 홈 진입

3
USER

회원가입 탭에서 가입

이메일·비밀번호 입력 → 필수 동의(개인정보) 체크
선택 동의(말투 학습·민감정보) 체크 후 [동의하고 가입하기]

4
SYSTEM

인증 처리

Supabase Auth 계정 생성 → user_profiles 프로필 저장
선택 동의를 user_consents에 기록

실패 시한글 에러 안내 ("이미 가입된 이메일입니다" 등)
성공 시같은 창이 문서 첨삭 홈으로 전환
◆
BRANCH

글 종류 선택

편지 / 논문 / 과제 / 블로그 중 선택 → 선택값이 첨삭 컨텍스트로 전달됨

5
USER

긴 글 붙여넣기 → [다듬기] 클릭

왼쪽 에디터에 발표 대본·이메일·자소서 등 붙여넣기

6
SYSTEM

첨삭 실행

로딩 표시("글을 다듬고 있어요...")
Gemini가 글 종류 맥락 + 나의 말투 프로필을 반영해 교정
원문·교정본·변경 요약을 DB에 기록

7
RESULT

오른쪽에 결과 요약 카드 표시

다듬어진 전문 + 변경 요약 3개 + [결과 보기] 버튼

8
USER

[결과 보기] 클릭

화면이 좌우 스왑: 왼쪽=최종 결과 / 오른쪽=교정 리포트

9
SYSTEM

교정 리포트 렌더링

틀린 부분 항목별 카드 + 근거 설명
항목 ↔ 왼쪽 결과를 잇는 빨간 점선 연결선

10
USER

복사 or 리포트 열기

[복사하기]로 최종본 확보, 또는 우하단 📊 FAB 클릭

11
SYSTEM

나의 말투 리포트 화면

"리포트 생성" → 누적 교정 로그 클러스터링
TOP 5 어법 실수 · 말투 습관 태그 · 개선 제안 표시
같은 날 재요청 시 캐시된 스냅샷 응답

기록 부족 시"리포트 생성하기" CTA만 표시
충분 시대시보드 + 랭킹 + 제안 렌더링
Flow B · 메뉴바 → 빠른 다듬기
1
USER

메뉴바 아이콘 ✦ 클릭

언제든 접근 가능 (앱 창과 독립)

2
SYSTEM

팝오버 홈 표시

헤더(로고+Magic Note) + 중앙 입력 폼
상대방/본인 필드 · 어투 드롭다운 · "막혔나요?" 힌트

◆
BRANCH

컨텍스트 입력 (모두 선택)

상대방("담당 교수님") · 본인("학부 3학년") · 어투("정중하게")
입력 안 하면 해당 항목은 프롬프트에서 생략

3
USER

메시지 입력 후 ⏎ 또는 ↑ 클릭

작성 중이던 답장/초안을 그대로 붙여넣기

4
SYSTEM

피드 전환 + 말풍선 재표시

입력값이 네이비 말풍선으로 피드에 남고
스피너 + shimmer 로딩 행 표시
(받는 사람/보내는 사람/어투가 프롬프트에 합성됨)

5
SYSTEM

미러 분석 카드 표시

"이렇게 읽힐 수 있어요" 피드백 박스 (말투 인상·의도 요약)
분석 상태 태그 2×2 — 위험도에 따라 경고 색상 자동 변경

6
USER

[교정 문장 확인하기] 클릭

분석을 확인하고 다음 단계 진행

7
RESULT

최종 결과 카드

교정 완료 미리보기 표시

8
USER

[복사하기] 클릭 → 메신저에 붙여넣기

버튼이 "복사 완료 ✓"(버건디)로 잠깐 전환

9
SYSTEM

백그라운드 학습

원문이 DB에 누적되고 5개마다 말투 프로필 자동 갱신
→ 다음 다듬기부터 내 말투가 점점 반영됨

예외 케이스
SYSTEM

서버 꺼짐 / 네트워크 오류

"서버에 연결할 수 없습니다" 안내 → 검토 모드는 Gemini 직접 호출로 폴백

SYSTEM

미로그인 상태

문서 홈 진입 불가(로그인 게이트)
메뉴바는 Gemini 직접 호출로 동작하되 학습·개인화 미적용
