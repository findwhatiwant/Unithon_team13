⌘ 진입점 A — 응용 프로그램 실행 (Dock)
🔐 로그인 / 회원가입
  • 이메일 + 비밀번호 입력
  • 개인정보 수집 동의 필수
  • 말투 학습·민감정보 동의 선택
↓
로그인 성공
📄 문서 첨삭 홈 — 긴 글 검토
  • 글 종류 선택 편지 · 논문 · 과제 · 블로그
  • 좌: 원본 입력 에디터 + [다듬기]
  • 우: 결과 영역 (빈 상태 → 첨삭 결과)
  • 우하단 📊 리포트 버튼 FAB
↓
[다듬기] 완료 후 [결과 보기]
✅ 최종 결과 (좌측 전환)
  • 다듬어진 전문 보기
  • [복사하기] / [원본 보기] 전환
⇄
📋 교정 리포트 (우측 전환)
  • 틀린 부분 항목별 목록
  • 항목별 근거 설명
  • 원본 ↔ 항목 빨간 연결선
↓
📊 리포트 FAB 클릭
📊 나의 말투 리포트
  • 요약 대시보드 — 검토 글 수 · 누적 교정 · 최다 실수
  • 자주 틀리는 어법 TOP 5 빈도 순위
  • 내 말투 습관 태그
  • 개선 제안
  • [← 뒤로가기] / [갱신]
✦ 진입점 B — 메뉴바 아이콘 클릭
🏠 빠른 다듬기 홈 (팝오버)
  • 상대방 입력 텍스트
  • 본인 입력 텍스트
  • 어투 선택 정중 · 부드럽 · 친근 · 아련
  • 중앙 캡슐 입력창 + ↑ 전송
  • "막혔나요?" 힌트 텍스트
↓
전송 (⏎)
💬 대화 피드 스트림
  • 입력한 메시지 말풍선 재표시
  • "이렇게 읽힐 수 있어요" 분석 카드 미러 분석
  • 분석 상태 태그 (의도/톤/구조/위험)
  • 최종 미리보기 + [복사하기]
↓
추후 확장
🧩 추천 초안 3가지 (계획)
  • 기본형 / 부드럽게 / 명확하게 후보 카드
  • 선택 → Mirror 확인 → 최종 복사
  • 백엔드 /api/compose 연동 준비 완료
