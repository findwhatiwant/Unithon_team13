2. 문서 첨삭 홈

긴 글 검토 전용 윈도우 · 좌 입력 / 우 결과 분할
헤더: 로고 + 로그인 이메일 + [로그아웃]
글 종류 카테고리 칩: 편지 · 논문 · 과제 · 블로그
좌측: 원본 에디터 (종류별 플레이스홀더)
우측: 결과 영역 (빈 상태 안내)
우하단 📊 리포트 FAB (입력 시 활성화)
빈 상태: 안내 문구 로딩: 스피너 + "글을 다듬고 있어요..."
[다듬기] → [결과 보기]

3. 결과 보기 (좌우 전환)

왼쪽엔 최종 결과가, 오른쪽엔 교정 리포트가 배치됨
좌 · 최종 결과
다듬어진 전문 (스크롤·선택 가능)
[복사하기] → 복사 완료 ✓
[원본 보기] 되돌리기 링크
우 · 교정 리포트
틀린 부분 항목별 카드 (번호 배지)
항목별 근거 설명
원본 ↔ 항목 빨간 점선 연결선
오류 없음 상태 표시
POST /api/refine message_sessions 저장 style_profile 주입 (맞춤 첨삭)
📊 리포트 FAB 클릭

1. 빠른 다듬기 홈 (팝오버)

360×520 글래스 프레임 · 헤더 로고 + Magic Note
상대방 입력 필드 텍스트
본인 입력 필드 텍스트
어투 드롭다운: 정중하게 · 부드럽게 · 친근하게 · 아련하게

"막혔나요?" 회색 힌트 텍스트
푸터: 설정 버튼 + 저작권 텍스트
